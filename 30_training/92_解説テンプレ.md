# 解説テンプレ — 解いた問題の記録フォーマット

labuladong式の「1問=1解説」を積み上げる。解いたら以下をコピーして `10_atcoder_notes/` の該当ファイル(abc437.md の形式)か週の教材mdに書く。**5分で書ける分量でいい。考察ログと学びが本体**。

```markdown
## ABCxxx D: 問題タイトル

**問題**: https://atcoder.jp/contests/abcxxx/tasks/abcxxx_d (diff: xxx)
**一言で**: 「◯◯ときたら◯◯」 ← ひらめき辞書の言葉で
**結果**: ◎自力AC(25分) / ○ヒント / △解説AC

### 考察ログ(時系列で正直に)

- 最初◯◯だと思った → 制約N≤2e5でO(N^2)は無理と気づく
- 「最大値の最小化」の形に言い換えられた → 答えで二分探索

### 解法

1. check(x) を「xで達成可能か」と定義
2. ...(箇条書き3〜5行で)

### 計算量

O(N log max A)

### 実装の罠(ハマった所)

- 和がintを溢れた / 境界のok/ng初期値

### 学び → 辞書・武器庫への反映

- [ ] 91_ひらめき辞書に追記: 「◯◯ときたら◯◯」
- [ ] 新テンプレなら src/knowledge/ に追加
```

## 運用のコツ

- **考察ログが一番価値がある**。中国系リポジトリが強いのは「正解」でなく「どう思いついたか」を書いているから。間違った方針も消さずに残す
- △(解説AC)の問題は、1週間後の再実装が終わったら「◎に昇格」と追記する
- 月1回、自分の解説を読み返して「一言で」だけを縦に眺める → それがあなた専用の頻出パターン集になる
