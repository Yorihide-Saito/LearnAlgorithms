# Week 1-2: 全探索・二分探索

## 学習目標

- 制約を見た瞬間に「N≤8なら順列全探索、N≤20ならbit全探索、N≤10^5でソート済みっぽければ二分探索」と反射できる
- 「答えで二分探索(判定問題化)」を自分の武器にする。460 D で「普通に二分探索だけでよかった」と振り返った弱点はここで潰す

## パターン最小知識

**bit全探索**: N個の選ぶ/選ばないを `for (int bit = 0; bit < (1 << N); bit++)` で全列挙。`bit >> i & 1` でi番目の採否。

**答えで二分探索**: 「最大値の最小化」「◯◯できる最大のX」ときたら、`check(x) = xで達成可能か?` という判定関数を作り、可能/不可能の境界を二分する。

```cpp
ll ok = 0, ng = 1e18;  // check(ok)=true が不変条件
while (abs(ng - ok) > 1) {
    ll mid = (ok + ng) / 2;
    (check(mid) ? ok : ng) = mid;
}
```
