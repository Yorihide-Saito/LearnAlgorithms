# ひらめき辞書 — 「〜ときたら〜」典型パターン

「ひらめき」の正体はパターン照合。考察に詰まったら上から順に当てはめる。**解説ACのたびに自分の言葉で行を追加していくこと**(この辞書を育てるのが本体)。

## 制約から逆算(最初にやる)

| 制約 | 想定計算量 | 候補 |
|---|---|---|
| N ≤ 8 | O(N!) | 順列全探索 |
| N ≤ 20 | O(2^N) | bit全探索・bitDP |
| N ≤ 40 | O(2^(N/2)) | 半分全列挙 |
| N ≤ 3000 | O(N^2) | 2重ループDP・区間DP |
| N ≤ 2×10^5 | O(N log N) | ソート・二分探索・priority_queue・セグ木 |
| N ≤ 10^7 | O(N) | 累積和・尺取り・篩 |
| N ≤ 10^18 | O(log N)〜O(1) | 二分探索・数学・ダブリング・行列累乗 |
| クエリQ ≤ 2×10^5 | 1クエリO(log) | 前計算+二分探索・BIT/セグ木 |

## 探索・二分

- 「最大値の最小化」「最小値の最大化」ときたら → **答えで二分探索**(判定問題化)
- 「◯◯以上になる最小のx」ときたら → 単調性を確認して二分探索
- 「ソートしても答えが変わらない」ときたら → まずソート(貪欲・二分の前処理)
- 「2つの配列から1つずつ選ぶ」ときたら → 片方を固定してもう片方を二分探索
- 「3つ組を数える」ときたら → 真ん中を固定して左右を数える

## 区間・列

- 「区間の和を何度も」ときたら → 累積和
- 「区間全体に加算、最後に一括で見る」ときたら → いもす法
- 「条件を満たす連続部分列の数/最長」ときたら → 尺取り(単調性の確認を忘れずに)
- 「部分列(連続でない)の最長」ときたら → LIS/DP
- 「区間の和 = K」で負の数を含むなら尺取り不可 → 累積和+map(zero-sum ranges)
- 「隣同士の操作・入れ替え」ときたら → 転倒数(BIT)か偶奇の不変量

## DP

- 「i番目まで見て状態がj」で場合の数/最大最小 → 基本DP。まず日本語でdp定義を書く
- 「選ぶ/選ばない」ときたら → ナップサック型
- 「直前の選択に依存」ときたら → 状態に直前の選択を積む
- 「値の範囲が大きく個数が小さい」ときたら → **軸の交換**(Knapsack 2型)
- 「訪問順序を全部試したいがN≤17」ときたら → bitDP
- 「両端から取っていく」ときたら → 区間DP dp[l][r]
- 「N以下の数で条件を満たすものを数える」ときたら → 桁DP
- 「木の上で部分木ごとに集計」ときたら → 木DP(DFS帰りがけ)

## グラフ

- 「マス目の最短手数」ときたら → BFS(重みなし最短路はBFS一択)
- 「コストが0と1だけ」ときたら → 01-BFS(deque)
- 「コストが正の重み」ときたら → ダイクストラ
- 「グループ分け・連結判定・クエリで辺追加」ときたら → UnionFind
- 「辺を壊す・削除する」ときたら → **クエリ逆順**にして追加に読み替え+UF
- 「AとBは同じ/違うグループ」ときたら → 二部彩色 or 重み付きUF
- 「操作で状態が変わる。最小手数は?」ときたら → 状態を頂点、操作を辺にしてBFS(グラフに見えない問題ほどこれ)
- 「頂点kを経由する最短路」ときたら → 両側からダイクストラ
- 「2^N倍・K番目に大きい経路」など巨大な繰り返し → ダブリング

## 数学

- 「場合の数をmodで」ときたら → 階乗前計算のnCr
- 「少なくとも1つ含む」ときたら → 余事象(全体 − 含まない)
- 「複数条件の少なくとも1つ」ときたら → 包除原理
- 「gcd/約数が絡む」ときたら → 素因数分解・約数列挙はO(√N)
- 「積が巨大でオーバーフローしそう」ときたら → 比較を割り算に変形
- 「周期がありそう」ときたら → 小さいNで実験して周期検出(実験は正義)

## 貪欲・その他

- 「締切があるタスク」ときたら → 締切順ソート+間に合うか判定(+priority_queueで後悔)
- 「その場で最良を取り続けてよい?」ときたら → 交換論法で1行証明できたら貪欲
- 「逆から見る」: 削除→追加、最後の操作から考える、ゴールから逆算
- 「操作しても変わらない量(不変量)は?」: 偶奇・総和・mod
- 「圧倒的に要素の種類が少ない」ときたら → 座標圧縮 or 種類ごとに集計
- 「困ったら小さいケースを手で全部書く」: 実験→規則性→証明の順
